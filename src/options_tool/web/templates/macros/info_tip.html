{# Reusable explanation tooltip for "what does this label/decision mean?" Renders a small ⓘ glyph; hover OR click opens a dark popover with the explanation text (which may contain plain text plus inline HTML — the caller is responsible for trusted content). Usage: {% from "macros/info_tip.html" import info_tip %} {{ info_tip("STOP_LOSS = 当前 mark ≥ 2× 开仓 premium。") }} {{ info_tip("...", glyph="?") }} # alternate glyph {{ info_tip("...", width="w-96") }} # wider popover Why position:fixed (not absolute) --------------------------------- Many of our tables wrap cells in `overflow: hidden` for rounded corners. An absolutely-positioned popover would get clipped at the table edge — so the *last* row's ⓘ would have its tooltip cut off at the table bottom. We compute the icon's viewport coords on open and position the popover with `position: fixed`, which escapes every ancestor's overflow box. The popover anchors its top-right corner to the icon's bottom-right (so it grows down-and-left). When the icon sits near the bottom of the viewport, it flips to grow up-and-left instead — handled in `place()`. Hover (desktop) and click (mobile / pinning) both open; mouseleave or click-outside closes. Each instance has its own x-data, so HTMX inner swaps don't leak open state. #} {% macro info_tip(text, glyph="ⓘ", width="w-72") %} {# trust the caller — explanation text is template-author-controlled and may contain inline HTML like /
